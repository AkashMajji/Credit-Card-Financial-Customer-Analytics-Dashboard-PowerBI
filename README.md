## 🎯 Project Objective

The objective of this project is to analyze credit card financial and customer data through an interactive Power BI dashboard.

The dashboard helps identify:

- Revenue performance
- Transaction activity
- Interest earned
- Transaction amount
- Customer income patterns
- Customer demographics
- Card category performance
- Transaction type performance
- Customer job segments
- Education and age groups
- Geographic revenue distribution

---

## 📌 Dashboard Pages

### 1. Credit Card Transaction Report

The transaction report focuses on overall financial and transaction performance.

### Key KPIs

| KPI                | Value |
| ------------------ | ----: |
| Total Revenue      |   57M |
| Total Interest     |    8M |
| Transaction Amount |   46M |
| Transaction Count  |  667K |

### Analysis Included

- Quarterly Revenue & Transaction Count
- Revenue by Customer Job
- Revenue by Education Level
- Revenue by Expenditure Type
- Revenue by Card Category
- Revenue by Transaction Type
- Card Category performance
- Revenue, Transaction Amount and Interest Earned by Card Category

The quarterly analysis shows revenue remaining around 14M across Q1–Q4, while transaction count increases from 163K in Q1 to 173K in Q4.

## 🔍 Key Insights

### Financial Performance

- Total revenue generated is **57M**.
- Total interest earned is **8M**.
- Total transaction amount is approximately **46M**.
- Total transaction count is approximately **667K**.

### Customer & Product Insights

- **Blue card category** contributes the highest revenue at approximately **47M**.
- **Businessmen** contribute the highest revenue among the customer job groups at approximately **18M**.
- **Graduate customers** contribute approximately **23M** in revenue.
- **Swipe transactions** contribute approximately **36M**, making them the largest transaction type shown.
- The **High income group** contributes approximately **23M** in revenue.
